# Figma Asset Extraction (Python and Node)

This folder contains two scripts (Python and Node.js) to extract images and icons from a Figma screen JSON into the project's assets directory.

- Python: `extract_figma_assets.py`
- Node.js: `extract_figma_assets.js`

Both versions do the following:
- Parse a Figma screen JSON (e.g., `attachments/screen_371:365.json`).
- Detect:
  - Raster images (`imageUrl` -> download).
  - Local images (`imagePath` -> copy).
  - Icons/vectors (`figma_type: "VECTOR"` or `type: "icon"`).
- For vector/icon nodes:
  - If you provide Figma API credentials (`FIGMA_TOKEN` and `FIGMA_FILE_KEY`), the script downloads real SVGs via Figma's `images` API.
  - Otherwise, it generates placeholder SVGs with correct dimensions.

All assets and a manifest are written to the target assets directory.

## Quick Start

From repo root:

Python:
```bash
python task-management-web-app-41-54/todo_frontend/scripts/extract_figma_assets.py \
  --input-json attachments/screen_371:365.json \
  --assets-dir assets/figmaimages
```

Node:
```bash
node task-management-web-app-41-54/todo_frontend/scripts/extract_figma_assets.js \
  attachments/screen_371:365.json \
  --out assets/figmaimages
```

NPM script (Node):
```bash
npm --prefix task-management-web-app-41-54/todo_frontend run extract:figma:node
```

This will:
- Download any `imageUrl` images.
- Copy any `imagePath` files if present.
- Generate placeholder SVGs for icon/vector nodes.
- Write a manifest: `assets/figmaimages/figma_assets_manifest.json`.

## Optional: Real SVGs via Figma API

If you have a Figma personal access token and file key, you can pull real SVGs for vector nodes.

Set environment variables:
```bash
export FIGMA_TOKEN=YOUR_FIGMA_TOKEN
export FIGMA_FILE_KEY=YOUR_FILE_KEY
```

Or pass via CLI:
- Python: `--figma-token "$FIGMA_TOKEN" --file-key "$FIGMA_FILE_KEY"`
- Node: `--token "$FIGMA_TOKEN" --file-key "$FIGMA_FILE_KEY"`

Notes:
- The JSON must contain node IDs that correspond to the same file key you provide.
- Without valid IDs/file key, Figma will not return image URLs for vectors.

## Output Manifest

`assets/figmaimages/figma_assets_manifest.json` contains:
- `downloaded`: assets fetched from `imageUrl`.
- `copied`: assets copied from local `imagePath`.
- `generated_svg`: SVGs either fetched via API or placeholder-generated.
- `skipped`: nodes the script couldn't process (with reasons).

## Troubleshooting

- "Input JSON not found": verify the path you pass to the script from your current working directory.
- "imagePath_not_found": the local file path inside the JSON doesn't exist in the repo.
- No SVGs downloaded for vectors: ensure you provided correct `FIGMA_TOKEN` and `FIGMA_FILE_KEY`. Otherwise placeholders are expected.

## Security

- Do not hard-code secrets. Use environment variables or CI secrets.
- Scripts read `FIGMA_TOKEN` and `FIGMA_FILE_KEY` from environment variables unless passed via CLI flags.
