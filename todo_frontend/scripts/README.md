# Figma Asset Extraction

This folder contains a script to extract images and icons from a Figma screen JSON into the project's assets directory.

## What it does

- Parses a Figma screen JSON (like the one in `attachments/screen_371:365.json`).
- Detects:
  - Raster images referenced via `imageUrl` (downloads them).
  - Local images referenced via `imagePath` (copies them).
  - Icons/vectors (figma_type `VECTOR` or type `icon`).
- For vector/icon nodes:
  - If you provide Figma API credentials (`FIGMA_TOKEN` and `FIGMA_FILE_KEY`), it downloads real SVGs via Figma's `images` API.
  - Otherwise, it generates placeholder SVGs with correct dimensions and a label.

All assets and a manifest are written to the target assets directory.

## Prerequisites

- Python 3.8+
- Internet access (if downloading from `imageUrl` or using Figma API)

## Usage

From the repo root:

```bash
python task-management-web-app-41-54/todo_frontend/scripts/extract_figma_assets.py \
  --input-json attachments/screen_371:365.json \
  --assets-dir assets/figmaimages
```

This will:
- Download any `imageUrl` images.
- Copy any local `imagePath` files if present.
- Generate placeholder SVGs for icon/vector nodes.

You should see output assets in `assets/figmaimages/` and a manifest at:
`assets/figmaimages/figma_assets_manifest.json`.

## Optional: Real SVGs for Vectors via Figma API

If you have a Figma personal access token and file key, you can pull real SVGs for vector nodes.

Set environment variables:

```bash
export FIGMA_TOKEN=YOUR_FIGMA_TOKEN
export FIGMA_FILE_KEY=YOUR_FILE_KEY
```

Or pass via CLI:

```bash
python task-management-web-app-41-54/todo_frontend/scripts/extract_figma_assets.py \
  --input-json attachments/screen_371:365.json \
  --assets-dir assets/figmaimages \
  --figma-token "$FIGMA_TOKEN" \
  --file-key "$FIGMA_FILE_KEY"
```

Notes:
- The JSON must contain node IDs that correspond to the same file key you provide.
- Without valid IDs/file key, Figma will not return image URLs for vectors.

## Output Manifest

`assets/figmaimages/figma_assets_manifest.json` contains:
- `downloaded`: assets fetched from `imageUrl`.
- `copied`: assets copied from local `imagePath`.
- `generated_svg`: SVGs either fetched via API or placeholder-generated.
- `skipped`: nodes the script couldn't process (with reasons).

## Troubleshooting

- "Input JSON not found": check the path you pass to `--input-json`.
- "imagePath_not_found": the local file path inside the JSON doesn't exist in repo; it may already be in `assets/figmaimages` under a different name.
- No SVGs downloaded for vectors: ensure you provided correct `FIGMA_TOKEN` and `FIGMA_FILE_KEY`. Otherwise placeholders are expected.
